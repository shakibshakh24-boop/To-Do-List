# Project name: To-Do List Web App

This project is a simple and interactive To-Do List web application built using HTML, CSS, and JavaScript

## Key Features:
**Add Tasks**
**Complete Tasks**
**Delete Tasks**
**Filter Tasks**
**Store Tasks**
**Size Adjusts to Device**

## Architecture (Tech Stack):
HTML5: Used to create the webpage structure, including the input field, buttons, and task list.

CSS3: Used to style the website, including colors, spacing, layout, and responsive design.

JavaScript: Used to make the website interactive by doing the task creation, completion, deletion, filtering, and local storage

## Components: 
index.html: Contains the main structure of the webpage.

styles.css: Controls the visual appearance of the website.

script.js: Handles the functionality of the To-Do List.
