# Project name: To-Do List Web App

This project is a simple and interactive To-Do List web application built using HTML, CSS, and JavaScript

## Key Features:
**Add Tasks**
**Complete Tasks**
**Delete Tasks**
**Filter Tasks**
**Store Tasks**
**Size Adjusts to Device**

## Architecture (Tech Stack):
HTML5: Used to create the webpage structure, including the input field, buttons, and task list.

CSS3: Used to style the website, including colors, spacing, layout, and responsive design.

JavaScript: Used to make the website interactive by handling task creation, completion, deletion, filtering, and local storage

## Components: 
index.html: Contains the main structure of the webpage.

styles.css: Controls the visual appearance of the website.

script.js: Handles the functionality of the To-Do List.

## How to Clone the project and open it on Localhost

**You need Node.js installed before doing this.**

1. Clone the repository
git clone https://github.com/shakibshakh24-boop/To-Do-List.git
2. Open the project folder
cd To-Do-List
3. Install Dependencies
npm install
4. Configure Environment Variables
Create a .env file in the main project folder
Add session secret: SESSION_SECRET=your_private_random_secret
5. Start the Backend and Frontend
npm run dev
6. Open the Website
http://localhost:8000
7. Stop the application
Ctrl + C
